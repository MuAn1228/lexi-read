# 复习词卡与详细注解

生词复习的释义不再依赖文章原句。墨墨导入、手动加入以及阅读中标记的词，使用同一套通用词典；没有原句也可以揭晓中文释义、音标、完整义项和词形变化。有真实原句时，另外提供按需的语境讲解，避免把通用词义当成本句含义。

## 使用

1. 打开生词复习，先回想，点击「揭晓释义」；填空模式检查或揭晓答案后同样展示注解。
2. 本地词典先显示。配置墨墨 Token 后，仅为当前揭晓的词读取个人注解，并将它放在本地词典前面。
3. 默认开启「自动补充详细讲解」。墨墨没有同时提供中文释义和有中文译文的例句、且本机没有成功的完整讲解时，调用已配置的 Agnes 补充。内容包括逐项中文解释、词性、双语例句、搭配、用法提示和易混辨析。
4. 成功讲解保存在本机，下次直接查看。关闭自动补充后，仍可点击「补充详细例句与用法」。开关在本次应用会话内跨卡保持，刷新后恢复默认开启。
5. 生成不影响自评。可点击「前往自评」，或停止等待、重试。切词、切页、关闭窗口后不展示旧请求结果；停止等待不保证撤销已经发给供应商的请求，已完成的后端结果仍可缓存。

打开词卡只预读本地词典，不请求墨墨或 AI；揭晓才启动当前词的补充。不会静默扫描整个词库、一次性生成数千份讲解，也不会因为读取释义新增学习事件、修改掌握状态或调整复习日期。没有到期词时仍按原规则显示复习安排，不人为把全部词设为到期。

## 墨墨能力及来源

官方内容接口返回的是用户自己创建的释义、例句和助记，不是墨墨内置词典全部义项。没有个人内容时显示空结果并使用本地词典和 Agnes；不将“个人注解为空”解释为“墨墨没有这个词义”。

- 官方文档：<https://open.maimemo.com/>，接口规范：<https://open.maimemo.com/api_bundle.yaml>。
- 先用 `GET /api/v1/memo/vocabulary?spelling=...` 获取词 ID，然后只读 `interpretations`、`phrases`、`notes`，均使用 `voc_id`。
- 已删除内容不显示；未发布的本人释义仍可保留。按纯文本显示，不执行个人内容里的 HTML。
- API 限流为 20 次/10 秒、40 次/分钟、2000 次/5 小时。复用学习同步的全局节流，当前词最多四个只读 GET，并限制总时间、响应大小和条数。
- 注解缓存位于 `DATA_DIR/maimemo-annotations`，按本机用户、凭证指纹和精确词面隔离，文件不保存 Token。成功缓存 24 小时，空结果 6 小时，失败 60 秒；明确更新也保留 60 秒冷却。失败刷新保留已有注解。
- 仅本地模式启用个人墨墨能力；公开模式不读取或返回个人缓存，注解 POST 返回 404。

## 本地覆盖

本次本机词库核对为 4,427 条：4,423 条由 ECDICT 提供中文义项，另外四条由精确匹配的「词间补充注解」提供自写解释、双语例句、用法提示和参考链接。补充内容不冒充 ECDICT、墨墨或 AI。

补充条目包括 `horizontal wind vector`、`leap of faith`、`microwavable` 和 `honourary`。最后一项明确提示核对拼写，条件解释对应标准拼写 `honorary` 的词义，保留原词和学习记录，不自动更正。实现及来源见 `backend/services/supplemental_dictionary.py`。

这表示现有词库全部有本地中文注解，不表示已批量为全部词生成 AI 完整课程。以后新导入的特殊词仍可能不在词典中，界面会说明缺失并尝试按当前词补充，无法确认的拼写不编造。

## 应用接口

| 接口 | 行为 |
| --- | --- |
| `GET /api/dictionary/{word}` | 本地词典、当前用户 AI 成功缓存、当前凭证下墨墨缓存；不访问远端 |
| `POST /api/dictionary/{word}/annotations` | 只读墨墨个人内容，不调用 AI；可选 `{ "refresh": true }` 更新 |
| `POST /api/dictionary/{word}/explain` | 生成或复用通用详细讲解；沿用模型预算与校验 |
| `POST /api/review/meaning` | 按真实原句讲解语境含义；不替代通用词典 |

共享 `WordAnnotations` 展示组件用于复习卡与词典弹窗。当前词的请求带取消信号及作用域序号，禁止迟到结果污染下一张卡；失败不会清空已有本地词义。
