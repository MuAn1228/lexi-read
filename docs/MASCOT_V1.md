# Lexi 阅读助手 V1 · 2026-10-25

## 使用

刷新本机词间页面即可看到阅读助手。拖动角色调整位置；点击显示一句短提示；右键、长按约 500ms 或点击 `…` 打开设置。支持三档大小、关闭点击台词、恢复位置和隐藏。页头眼睛按钮可隐藏/恢复角色，「问 Lexi」及角色下方对话按钮可打开 Agnes 学习助手。

### Agnes 学习助手（2026-10-25）

角色已接入现有 Agnes 服务，支持结合当前词/原句/文章讲解、记忆提示、四选一练习和自由追问。只有主动提问时请求模型；思考、成功和失败与真实请求同步。词典新增「和 Lexi 学这个词」。会话仅保留本轮，支持停止、重试、清空和答后解析；不修改掌握度或复习安排。入口、上下文边界和完整验证见 [AI_COMPANION.md](AI_COMPANION.md)。

### 角色互动增强（2026-10-25）

单击立即随机点头、歪头或轻跳，连续的随机动作不重复；320ms 内第二次点击切换为摸头。菜单提供「点点头 / 歪歪头 / 轻轻跳 / 伸个懒腰 / 摸摸头」，选择后自动收起菜单，手机上也能看到动作。动作持续 600–1100ms，450ms 冷却、无队列；连续点击不能延长正在播放的摸头。心形、笑脸、问号等是独立表情贴纸，未修改原角色面部。

新增「角色动作与表情」设置，默认开启，旧配置自动兼容。关闭后保留原学习提示、状态灯和按压反馈。动作与原学习状态分层，AI 等待、重要结果和错误优先；拖动、取消、窗口失焦、切到后台、隐藏和专注模式会立即清理动作及双击计时。菜单在焦点落到页面时仍隔离标记快捷键，并支持 Escape 关闭。角色绘制裁切在原避让矩形内。

摸头临时显示原项目 `rua.gif`，约 1 秒后恢复原图；动图缺失时回到原图，再使用仓库原创兜底，不反复请求失败素材。系统减少动态效果偏好会阻止 GIF 加载和 CSS 动画，只显示静态反馈，运行中切换偏好也会立即停止 GIF。没有新增声音、模型调用、学习写入或依赖。

### 台词定位修复（2026-10-25）

气泡间隔 10px，按实际文字尺寸在上、下、左、右寻找位置，尖角随方向并对准角色。当前固定停靠版本只调整气泡的方向和宽度，不移动或缩小角色。先找正文外空白，再允许气泡浮在非交互内容上，但仍避开按钮、导航与通知。没有安全台词位置时以可访问提示兜底。拖动期间收起台词，松手、视口或字号变化后重新测量；菜单打开时暂停台词布局。

新增 `mascotBubblePosition.ts` 和对应 8 项测试。前端 241 项通过，七种窗口的日常/错误台词与原挂件、业务回归通过，详见 `VERIFICATION.md` 与 `work/qa-mascot-bubble/`。

### 早期滚动避让修复（已由固定停靠替代，2026-10-25）

自动避让保留用户选择的左/右侧，收起入口固定在该侧屏幕边缘，不能为寻找空位跳到另一侧。收起模式显示叶片入口，彻底去掉窄条裁切角色的显示方式；点击或键盘激活打开设置，重新有空位时恢复角色。找不到安全入口位置时暂时隐藏，不覆盖正文或按钮，也不改保存的设置。原有主动拖拽仍可换边；活动台词同样遵守所选侧。

新增 `mascotRestingPosition.ts` 和 8 项测试，前端共 249 项通过。左右偏好/四种宽度共 64 次滚动采样、原挂件及台词回归通过，详情见 `VERIFICATION.md` 与 `work/qa-mascot-scroll/`。

### 固定尺寸与持续显示（2026-10-25）

取消依据正文空位切换完整/迷你/窄条及自动隐藏。角色始终按用户大小设置与设备宽度计算唯一尺寸，位置只受手动拖动、用户设置及视口边界影响；滚动、业务状态与台词出现/消失都不改变外层尺寸和停靠点。左侧停靠在导航栏右边，避免被导航层盖住。只保留主动隐藏及原有专注/模态抑制。

角色采用悬浮模式，不再为寻找正文空白而离开停靠点，可能覆盖非模态页面内容；可拖动到合适位置或从设置隐藏。按压、伸展等有限动作仍可短暂变换图片，外层宽高不变。气泡通过 `fixedCharacter` 禁止组合移动，角色和气泡可使用不同障碍集合；旧收起菜单及裁切样式一并删除。

选词和保存掌握状态会触发轻微反应；主动分析语境、发现关联词及保存关联反馈会显示对应状态。AI 等待只表示真实请求正在进行，取消、切词或离开会静默撤销等待提示。助手不会自动说话、朗读、滚动页面、查词或写入学习记录。

## 事件与学习语义

| 事件 | 发送时机 | 视觉状态 |
| --- | --- | --- |
| `WORD_SELECTED` | 点击原文/词表，或主动进入下一词 | reading |
| `WORD_MARKED` | 原有保存请求已确认返回状态，包括复习自评 | KNOWN → success；UNKNOWN → thinking；UNCERTAIN → uncertain |
| `ANALYSIS_STARTED` | 点击语境释义/重试，立即响应；原有 300ms 防抖保留 | thinking |
| `ANALYSIS_SUCCESS` / `ANALYSIS_ERROR` | 当前分析确认成功/失败，忽略取消和迟到结果 | explaining / error |
| `RECOMMENDATION_STARTED` | 主动发现/刷新关联词或生成词汇拓展 | searching |
| `RECOMMENDATION_SUCCESS` / `RECOMMENDATION_ERROR` | 当前推荐确认成功/失败 | success / error |
| `FEEDBACK_SAVED` | KNOWN、UNKNOWN、USEFUL、NOT_USEFUL 的原有 POST 成功后 | success |

被动选词仍不是 LOOKUP；SHOWN、VIEWED 均不触发 FEEDBACK_SAVED。反馈请求的业务 UUID、失败重试、已有 API 路径及请求体保持不变。缓存读取不发送 AI 开始事件，不增加请求。统计刷新失败不会误报为 AI 失败。

视觉操作使用独立递增 ID，不占用业务 UUID，也不依赖 HTTPS 的 Web Crypto。每个进行中的请求进入 pending 集合，取消只移除所属操作并清理它的等待气泡；迟到结果找不到有效操作时直接忽略。并发请求完成后，短暂展示结果，再回到其他仍在进行的请求状态。

状态全集：`idle / reading / thinking / explaining / searching / success / uncertain / error`。没有 pending 或临时状态时回到 idle。它是纯视觉状态机，不执行请求、数据库写入、焦点移动或滚动。

## 气泡与动效

- 优先级：error(3) > AI 等待/结果(2) > 学习动作(1) > 点击日常台词(0)。低优先级不能盖住更重要的状态或气泡。
- 普通气泡最短间隔 2500ms；选词约 15%、标记约 12% 出现文字，每次仍可触发角色反应。AI 和错误不受普通冷却限制。
- 日常台词只在主动点击角色时显示，不自动闲聊；随机选择排除上一句。普通和 AI 气泡约 4 秒、错误约 7 秒，可主动关闭；请求状态可持续到真实请求结束。
- 推荐数量采用实际卡片数，最多 3；空结果使用中性提示。`source=offline` 只说明离线来源，不推断模型故障；仅显式 `fallback=true` 可使用回退文案，当前接入不会从 warning 文本猜测。
- 整体通过独立层实现：位置 translate、朝向 scaleX、按压 scale(1.04,.90)、反应和呼吸。松手吸附约 240ms，Q 弹约 210ms，呼吸 3.6s/2px。只有松手吸附才过渡位置，自动避让即时完成，避免角色追着滚动穿越正文。
- `prefers-reduced-motion: reduce` 关闭呼吸、状态动画、Q 弹和吸附过渡，保留即时状态、位置和文字。原角色按原图渲染；原创兜底采用 crisp-edges/pixelated。

## 布局、移动端与存储

Provider 在 `SpeechProvider` 内、`App` 外；Widget 通过 Portal 放在 body，不进入 OCR 或正文布局。挂件层级 15，低于 toast(20)、导航(35)、模态(40/80)；只有角色、菜单和气泡可接收指针，其余覆盖层穿透。

默认偏好右下角 24px。角色已按用户要求整体缩小，桌面标准宽度 96px（可调 72–120px），手机标准宽度 72px（可调 54–90px）且不超过视口 30%。同一窗口和大小设置下，滚动不改变尺寸和停靠坐标。正文和控件的滚动测量只参与台词定位，不影响角色显示；左侧停靠排除导航占用区域。气泡找不到安全空位时仅保留屏幕阅读器状态提示。

仅角色使用 `touch-action:none`；页面仍可正常滚动。主指针捕获，4px 阈值区分点击与拖动，拖动 1:1 无过渡，取消/失去捕获/窗口失焦均清理；重新抓住正在吸附的角色，从当前实际绘制位置继续。松手在左右或底部附近吸附，中间保留自由坐标；左边只镜像角色，文字保持正向。

viewport、visualViewport、窗口旋转和 CSS 安全区共同决定可用范围。布局与滚动变化合并到 rAF 测量，不持续轮询，不动画正文尺寸。专注阅读、导入/OCR/恢复和原生对话框打开时临时收起。

设置只存浏览器 **`lexi:mascot:config`**：`x / y / anchor / side / scale / hidden / idleBubbleEnabled / interactionEnabled`。坏 JSON、非法数字和存储不可用会安全降级。视口夹取、键盘弹出、避让和临时收起不覆盖用户保存的偏好，不发送 LearningEvent。
