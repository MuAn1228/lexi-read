# AI 等待体验

词间在详细释义与 Lexi 助手中提供真正的模型流式输出。收到摘要或回答片段后立即显示「生成中草稿，完成后核对」；正式义项、练习答案、缓存只采用完整且通过验证的结果。

## 使用

- 查单词、词典弹窗与生词复习：生成详细讲解时先显示摘要草稿，本地释义始终可以阅读；完成后展示完整义项和双语例句。
- Lexi 学习助手：讲解、记忆方法和普通问答逐步显示回答。出题模式等待完整验证后再显示题目，作答前不预览答案。
- 所有已接入的等待区域显示已用秒数；流式接口按实际连接、生成、核对阶段更新，普通请求显示等待模型响应。15 秒后提示可以继续等待或停止，没有估算完成百分比。
- 详细释义、助手、文章问答、短文生成、语境释义/推荐、句子解析和词汇拓展均提供停止等待。停止后保留问题、本地释义或已有结果，重试由用户主动点击。
- 短文停止后保留同一请求编号与设置，重试可取回本次生成；保存文章的收据不受停止操作影响。助手更新不会把正在翻阅旧对话的滚动位置拉回底部，小窗口保留头部停止按钮。

## 协议与边界

新增 `POST /api/dictionary/{word}/explain-stream`、`POST /api/assistant/messages/stream`。事件为 `status`、`preview`、`result`、`error`；preview 是当前草稿快照，客户端替换显示，仅 result 表示成功。原 JSON 接口保留。

上游使用真实 `stream:true` 的 chat completions SSE。首次不兼容只有在 HTTP 404/415 或 400/422 明确表示不支持 stream 时，才在同一次业务预算内回退一次完整响应；网络错误、截断和无效结果不会自动再次调用模型。缓存命中直接返回完整结果，无伪造草稿。

流式生成在断连/停止时关闭上游响应、取消 worker 并阻止未完成缓存；普通非流式模块的「停止等待」取消前端等待和迟到显示，不承诺终止已经在服务器执行的模型工作。模型总生成耗时仍取决于服务响应，逐步显示用于提前阅读已有内容。

复用原有鉴权、预算、上下文复查、格式校验和缓存规则，无学习库迁移或新增依赖。SSE 队列合并草稿且有界；客户端支持跨字节 UTF-8、CRLF、多行数据、取消和终态检查，错误消息不透传提供方信息。

## 验证

- 前端全套 319 项；后端流式、传输、字典与助手相关 180 项通过。
- 浏览器 13 组：草稿早于结果、停止/截断/失败重试、词典弹窗、助手和出题保密、15 秒提示、普通 AI 模块取消与短文同编号重试、复习揭晓与自评、四种宽度/低动态、助手浏览旧记录不跳动和 340×260 停止入口。
- 本机真实 HTTP 提供方测试验证阻塞读取时取消能中断上游，未完成内容不缓存；普通英文查询和现有接口继续使用原逻辑。
- 真实 Agnes 简短问答一次联调成功：首份草稿约 2.996 秒，完整结果约 3.09 秒。仅代表该次 19 字回答，不作为普遍速度保证。
- 本机已缓存 eye 的流式接口只返回 result，输入校验保留 HTTP 422。合成 UI 写入均在测试接口拦截；真实联调未修改词库状态。
