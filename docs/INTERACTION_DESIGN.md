# 阅读交互动效说明 · 2026-10-24

本轮只增强现有前端的焦点、状态和等待反馈。沿用暖白纸面、绿色、英文衬线及中文宋体标题，保留左侧导航。没有新增依赖，没有改动后端、API contract、数据库、掌握度算法或学习事件定义。

## 体验与动效

| 位置 | 用户得到的反馈 | 实现边界 |
| --- | --- | --- |
| OCR 选词 | 180ms 轮廓提示；选中与掌握状态同时可见 | 无 transform，不插值词框位置或缩放 |
| 词表定位 | 当前行的绿色标记、背景过渡；只滚动词表内部 | 不移动整页，不动画重排长词表 |
| 状态保存 | 原行按绿色、陶土色、琥珀色短暂反馈 | 只在已确认状态变化后播放，未标记保持独立 |
| 阅读进度 | 进度条追随当前值，数字轻微淡入 | 实际数值立即显示，不从零计数、不排队 |
| 语境切词 | 单词、状态、原句以 180ms / 5px 短暂出现 | 外框稳定；逐词内层继续隔离请求状态 |
| AI 等待 | 具体文案、骨架和小型处理中指示 | 只在真实请求期间显示，无虚构步骤或百分比 |
| 语境结果 | 释义、说明、重要程度依次出现 | 间隔 60ms，不变更内容或评分含义 |
| 关联推荐 | 最多三卡，60ms 间隔出现 | 保留原批次 key 和可见性记录规则 |
| 关联说明 | 280ms 高度展开，原因与反馈渐入 | 未展开内容 inert；仅主动展开记录 VIEWED |
| 关联反馈 | 按压、选中图标、局部保存与失败重试 | 不遮罩整张卡，保留 UUID 和失败请求 |
| 学习概览 | 带编号的密集档案列表、数字更新、详情展开 | 刷新保留上次结果，关闭详情回到来源按钮 |
| 词汇关联 | 在悬停或聚焦时强调箭头与关系类型 | 不添加力导向图，不把规则关系强度当成掌握率 |
| 导航和 Toast | 标题与活动项短暂淡入，提示进出 | 不为动画重新挂载整个学习空间 |
| 图文切换 | 180ms 淡切与真实图片加载占位 | 隐藏面 inert；缩放立即同步图片和词框 |

桌面三栏从 1440px 起等高，语境内容在面板内滚动；621–1170px 保留原文和词表并列、语境在下方；手机纵向排列。专注阅读保留独立布局，只捕获可见阅读面的锚点，容忍恢复时不足 1px 的像素舍入。

## 文件与组织

- `frontend/src/DocumentPanel.tsx`、`WordList.tsx`：阅读面切换、真实图片就绪、当前词与已确认状态反馈。
- `frontend/src/ContextPanel.tsx`、`RelatedWordCard.tsx`：稳定面板、局部加载、结果分层、渐进展开与无障碍焦点。
- `frontend/src/DashboardView.tsx`、`RelationsView.tsx`：概览档案、连续数据、真实数值与关系提示。
- `frontend/src/App.tsx`、`useFocusReading.ts`：移除外层语境 key、接入进度及提示组件、保留可见阅读锚点。
- `frontend/src/MotionPrimitives.tsx`：实际数字反馈与可退出 Toast；仅数字文字的 key 用于视觉更新。
- `frontend/src/interactionMotion.css`：统一 tokens、全局/概览/关联样式。
- `frontend/src/contextMotion.css`、`readerMotion.css`：语境与阅读动效；由 `main.tsx` 在既有样式之后导入。

统一时间为 120 / 180 / 280ms，分别用于操作反馈、内容切换和展开。没有为本轮安装 Motion、Tailwind 或其他库。

## 可访问性和性能

`prefers-reduced-motion: reduce` 下关闭新增动画、过渡和滚动动画；所有选择、展开、反馈、键盘标记和进度仍立即可用。状态同时有文字与按钮语义，隐藏内容不参与键盘操作。Toast 退出残影不重复播报。

没有给全部 OCR 框添加持续动画；没有动画缩放、长词表逐行入场、背景粒子、发光、卡片整体漂浮或庆祝特效。只有选中、刚更新、主动展开的内容及真实请求中的指示器需要动效。OCR 图片、stage、词框均保持 transform:none。

## 验证

各阶段 TypeScript / Vite 生产构建通过，原有前端测试 **203 passed**。隔离浏览器 **10 组通过**，包括四态、三栏与内部滚动、1/2/3、显式 AI 请求、SHOWN/VIEWED、同 UUID 重试、概览详情、1440/1024/768/390px、专注阅读及减少动态效果。

合成图片在 75/100/125/200% 缩放及 hover/selected 下词框误差小于 0.015px；这表示前端定位保持一致，不代表 OCR 识别本身无误。浏览器请求全部拦截为合成响应，没有真实学习写入、AI/OCR 或发音调用。图片专注切换后滚动位置回到原值，文字字号调整/退出的锚点误差不超过 1px。

工作目录 `work/qa-editorial-motion` 保存浏览器报告、合成截图与个人数据不变性检查，脚本在 `work/browser/editorial-motion-check.mjs`。合成截图不是用户真实统计。正式本机 18 张表及 `.env` 指纹前后相同，8000 静态首页和最终构建逐字节一致。
