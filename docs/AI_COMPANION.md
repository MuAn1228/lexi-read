# Lexi 与 Agnes 学习助手

2026-10-25，本机版已接入现有 Agnes 模型配置，无新增模型账号、依赖或数据表。

## 使用

刷新页面，点击角色下方「问 Lexi」或页头「问 Lexi」。设置菜单也有「和 Lexi 一起学」。角色仍保持缩小后的固定大小与位置，打开对话不会搬动角色。

- **讲解词句**：围绕当前词、原句和文章讲解含义与用法。
- **帮我记住**：给出联想方法与例句；提示模型区分联想与真实词源。
- **出一道题**：生成四选一练习；选择后点击「确认答案」才揭晓正确答案与解析。
- **自由追问**：可问词义、语法、近义词等英语问题。最近三轮成功回答用于接续对话；已作答的练习会带上用户选择与解析。

词库/阅读中的中文释义弹窗增加「和 Lexi 学这个词」，关闭词典后直接进入该词的助手上下文。专注阅读或正在执行隔离操作时，该入口明确禁用，不静默失败。其他页面可独立询问英语问题，不会带入之前阅读页的文章。

只有主动点击功能或发送问题时调用模型。最多输入 500 个 Unicode 字符，每轮最多 12 次成功提问；支持停止、失败重试与清空。对话仅在内存中，关闭、切换词句/文章或离开该上下文后清空。练习不会自动改变词库掌握状态或复习排期。

## 实现

`POST /api/assistant/messages`：

```json
{
  "mode": "explain",
  "message": "请结合原句解释这个词。",
  "document_id": 1,
  "occurrence_id": 2,
  "word": "curiosity",
  "history": []
}
```

模式为 `chat / explain / memory / quiz`。文档和出现位置可为空；单独的 `word` 支持词典入口。服务端验证当前用户的文档、单词归属及生成期间的文章变化；模型密钥留在后端。客户端不传整篇正文，服务端读取必要原句、学习状态及最多 8000 字符的文章片段，输出上限为现有配置与 1600 tokens 的较小值。

响应包含 `source / answer / quiz / context_limited / warning`。模型未启用、失败或结构不合法时返回明确不可用，不把预设文案当 AI 成功。出题由严格四选一结构承载，服务端覆盖引导语以防提前泄露选项，前端确认作答后才显示答案与解析。仍需结合具体语言语境核对 AI 内容；该助手不替代已有带精确原文引用的文章问答。

前端使用稳定 Provider 命令与单独快照传递上下文，面板按需加载。请求使用独立 operation ID 驱动角色思考/讲解/错误状态；停止、卸载、换上下文会中止并忽略迟到结果。面板开启期间隔离标记快捷键，即使发送按钮禁用后焦点落到 body 也不会意外标注单词。

面板在角色内侧或上方寻找位置，不改变角色尺寸。手机、横屏和键盘挤压的矮窗口使用紧凑布局，保留标题栏停止与关闭入口；滚动只发生在面板内部。

## 文件

| 文件 | 职责 |
| --- | --- |
| `backend/services/reading_assistant.py` | 请求/响应校验、上下文、模型与预算、状态复验 |
| `backend/api/assistant_routes.py` | 带鉴权的显式对话入口 |
| `frontend/src/mascot/MascotAssistantPanel.tsx` | 对话、取消/重试、练习揭晓、键盘与布局 |
| `frontend/src/mascot/mascotAssistant.ts` | 上下文类型、输入/响应校验、历史、请求与定位 |
| `frontend/src/mascot/mascotAssistant.css` | 绿色纸面样式、紧凑窗口布局 |

`MascotProvider / MascotWidget / MascotControls / MascotMenu` 接入口与角色状态；`App` 提供当前文档/单词及正文指纹，`DictionaryPanel` 提供独立词条入口。
